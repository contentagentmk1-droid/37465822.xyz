# 37465822.xyz

De publieke pagina's die Google eist voor de OAuth-consentscreen van MAINFRAME:
een homepage en een privacybeleid op een geverifieerd domein.

Meer is het niet. MAINFRAME zelf is een privé systeem en staat in een andere repo.

- `index.html` - wat MAINFRAME is
- `privacy.html` - wat er met Google-gegevens gebeurt
- `CNAME` - koppelt GitHub Pages aan 37465822.xyz

Wijzig je iets aan wat het systeem met Google-gegevens doet, werk dan
`privacy.html` bij en pas de datum bovenaan aan.
